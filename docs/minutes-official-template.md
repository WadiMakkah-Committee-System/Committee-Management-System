# "القالب العام" للمحاضر — التصميم

> المواصفات المعتمدة: مستند المشروع `minutes_template_spec.md` (Claude Project "ادارة اللجان").
> المرجع: محضر مجلس إدارة شركة وادي مكة للتقنية السادس لعام 2024م.
> المراحل: قاعدة البيانات ✅، الباك إند ✅، الفرونت إند ✅ (بانتظار المراجعة)، ثم الدمج والتطبيق على البيئتين.

## 1. الفكرة
قالب رابع اسمه **"القالب العام"** (`template_id = "general"`) بجانب القوالب الثلاثة الثابتة
في `MINUTES_TEMPLATES` (`backend/app/services/meeting_minutes_service.py`)، التي تبقى كما هي.
- يتاح مثل باقي القوالب، ويبدأ المحضر مع بداية الاجتماع.
- الأجزاء التلقائية تتزامن مع بيانات الاجتماع حتى يعدّلها المستخدم يدويًا.
- كل شيء قابل للتعديل حتى الاعتماد والإرسال للتوقيع.

الكود كله في `backend/app/services/minutes_general/`:

| الوحدة | المسؤولية |
|---|---|
| `formatting.py` | التاريخ الهجري (أم القرى) والميلادي واسم اليوم، الوقت (صباحاً/مساءً)، الترتيب بالكلمات |
| `editor_content.py` | التحقق من محتوى المحرر الغني (قائمة بيضاء) |
| `sections.py` | بناء الأقسام، المزامنة، دمج تعديلات المستخدم (دوال نقية) |
| `snapshot.py` | جمع بيانات الاجتماع من القاعدة (5 استعلامات ثابتة) |
| `pdf.py` | ملف PDF بشكل المحضر الأصلي |

## 2. قاعدة البيانات
ملف واحد: `db/migrations/0049_user_saved_signatures.sql`. جدول مستقل للتوقيع المحفوظ
(صف لكل مستخدم، PNG data URL، حد 300 ألف حرف، RLS، trigger لـ`updated_at`).
باقي محتوى القالب داخل `meeting_minutes.sections` (JSONB) — لا تغيير على أي جدول موجود.

## 3. هيكل الأقسام داخل `sections`
كل قسم: `{ id, kind, order, title, body, rev, data }`. الأقسام القديمة بلا `kind` = `text` ولا تتأثر.

| `kind` | `data` | التلقائي (يتزامن حتى التعديل) |
|---|---|---|
| `header` | `date_text`، `place_text`، `time_text`، `subject_text` | الكل |
| `title` | `line1`، `line2`، `meeting_number`، `meeting_year` | الرقم والسنة و`line2` |
| `rich` | `role` (opening / opening_followup / discussion / custom)، `heading`، `placeholder`، `content` | — |
| `members_table` | `caption`، `rows[]`: `key`، `auto`، `locked`، `name`، `role_label`، `mode_label`، `status_label` | خانات الصفوف التلقائية |
| `guests_table` | `caption`، `rows[]`: `name`، `mode_label`، `role_label` | خانات الصفوف التلقائية |
| `agenda_table` | `caption`، `rows[]`: `ordinal_label`، `title` | خانات الصفوف التلقائية |
| `topic` | `agenda_item_id`، `ordinal_label`، `heading`، `background_label`، `background`، `decision_label`، `decision_number`، `decision` | الترتيب، العنوان، رقم القرار |
| `closing` | `text`، `sign_off` | `text` (وقت الانتهاء) |
| `signatures` | `heading`، `rows[]`: `name`، `role_label` | العنوان وخانات الصفوف |
| `meta` | `removed_topic_keys` (داخلي، لا يُعرض ولا يُعدّل) | — |

`content` و`background` و`decision`: مستند المحرر بصيغة ProseMirror/TipTap
(`{"type": "doc", ...}`). المسموح: فقرة، عنوان (1–3)، قوائم مرقمة ونقطية، جدول
(مع دمج الخلايا)، سطر جديد، نص عريض/مائل/مسطّر، ومحاذاة. أي عنصر آخر يُرفض.

### قواعد المزامنة والتعديل
- **القفل:** أي خانة تلقائية يغيّر المستخدم قيمتها تُضاف لـ`locked` ولا تلمسها المزامنة بعدها. الخادم يحسب القفل بمقارنة القيمة الجديدة بالمخزّنة، ولا يقبل `locked` من الواجهة.
- **الحذف:**
  - صف تلقائي يحذفه المستخدم يُسجّل في `removed_keys` ولا يرجع.
  - موضوع تلقائي يُحذف يُسجّل في `meta.removed_topic_keys`.
  - الصف أو الموضوع اليدوي ما يتزامن أبدًا.
- **رقم المراجعة `rev`:** يزيد مع أي تغيير، سواء من المستخدم أو من المزامنة. الحفظ بـ`rev` قديم يرجع 409 ومعه نسخة القسم الحالية.
- **القفل على مستوى الصف في القاعدة:** كل حفظ أو مزامنة يقفل صف المحضر (`SELECT ... FOR UPDATE`). كذا حفظان متزامنان لقسمين مختلفين ما يمسح أحدهما الآخر.
- **التجميد:** المزامنة تشتغل في مرحلة التحضير (`preparing`) فقط. بعد الاعتماد يتجمّد المحضر.

### قواعد التعبئة
- **التاريخ:** `{اليوم} {هجري}هـ الموافق {ميلادي}م` بتوقيت الرياض. وإذا كان التاريخ خارج نطاق أم القرى، يُكتب الميلادي فقط.
- **المكان:** `remote` ← "عبر الاتصال المرئي"، و`in_person` ← `meetings.location`.
- **رقم الاجتماع:** 1 + عدد اجتماعات نفس اللجنة غير المحذوفة اللي موعدها في نفس السنة (بتوقيت الرياض) وقبل هذا الاجتماع.
- **الأعضاء:** الرئيس أولًا، ثم الأعضاء بترتيب إضافتهم، ثم أمين السر آخرًا. الصفة = اسم دور اللجنة.
- **الحالة:**
  - **عن بعد بعد البداية:** حاضر إذا له جلسة في `meeting_attendance`، وإلا غائب.
  - **قبل البداية، والاجتماع الحضوري:** فارغة ويختارها الرئيس.
- **آلية الحضور:** مشتقة من الحالة. الغائب ← "غائب"، وغيره ← "عن بعد" أو "حضوري".
- **الضيوف:** الضيوف المقبولون (حسابات `is_guest` المربوطة بالاجتماع)، والصفة الأولية "ضيف خارجي". ما يُحذفون تلقائيًا.
- **البنود والمواضيع:**
  - بند جديد يضيف صفًا في جدول البنود وقسم موضوع.
  - بند يُحذف ← يُحذف موضوعه إذا ما انكتب فيه شيء.
  - رقم القرار: `({ترتيب الموضوع}-{رقم الاجتماع}-{السنة})`، من رقم العنوان وسنته (حتى لو عُدّلا يدويًا).
- **وقت الانتهاء (بعد انتهاء الاجتماع فقط)، بالترتيب:**
  1. `ended_at` إذا كان مسجّلًا.
  2. الاجتماع عن بعد: آخر خروج فعلي من الغرفة.
  3. غير ذلك: موعد النهاية بعد أي تمديد.
- **التوقيعات:** كل أعضاء اللجنة والرئيس آخرًا. الضيوف لا يوقّعون. صورة التوقيع من `meeting_minutes_signatures` فقط.

## 4. نقاط الـAPI

| الطريقة | المسار | الوصف |
|---|---|---|
| POST | `/meetings/{id}/minutes/template` | `template_id: "general"` يبني القالب من الاجتماع |
| GET | `/meetings/{id}/minutes/detail` | يزامن الأجزاء التلقائية قبل العرض، ويبثّ `minutes.updated` إذا تغيّر شيء |
| PATCH | `/meetings/{id}/minutes/sections/{section_id}` | **جديد:** حفظ قسم واحد (`{section}` مع `rev`). يبثّ `minutes.section_updated`. 409 مع `current_section` |
| PUT | `/meetings/{id}/minutes/sections` | حفظ كامل (إضافة/حذف/ترتيب) مع نفس قواعد الدمج. يبثّ `minutes.updated` |
| POST | `/meetings/{id}/minutes/sign` | `signature_image` **أو** `use_saved: true`، و`save_for_later` مع الرسم |
| GET | `/meetings/{id}/minutes/pdf` | PDF بشكل المحضر الأصلي |
| GET / PUT / DELETE | `/users/me/signature` | **جديد:** توقيعي المحفوظ (للمستخدم نفسه فقط، والضيوف 403) |

## 5. ملف PDF
- **الترويسة في كل صفحة:** الشعار يسارًا، والتاريخ والمكان والزمان والموضوع يمينًا.
- **التذييل في كل صفحة:** صورة الورق الرسمي المستخرجة من المحضر الأصلي (`app/assets/letterhead/`)، ورقم الصفحة بالوسط.
- **الخطوط:**
  - الأصل بخطوط Microsoft غير قابلة للتضمين.
  - البديل للعربي: Noto Naskh Arabic (OFL — `app/assets/fonts/OFL-NotoNaskhArabic.txt`).
  - البديل للحروف اللاتينية والرموز: Times المدمج في PDF.
- **حدود معروفة:**
  - الخط المائل لا يظهر، لأنه لا يوجد خط عربي مائل.
  - الفقرة "المضبوطة" تُرسم محاذاة يمين.

## 7. الواجهة (الفرونت إند)
- **المجلد:** `frontend/src/features/meetings/minutes-general/`.
- **الورقة:** نفس ترتيب المحضر الأصلي، وتبقى بيضاء حتى بالوضع الداكن.
- **التحرير بالمكان:** كل حقل يتحرر مباشرة فوق الورقة. الحقول التلقائية عليها تلميح "يتحدث تلقائيًا"، وبعد تعديلها يدويًا تصير "معدّلة يدويًا" ولا تتغيّر مع الاجتماع.
- **الحفظ:** لكل قسم لوحده بعد توقف الكتابة (900ms) عبر PATCH، وزر "حفظ الآن". عند التعارض (409) يُستبدل القسم بنسخة الخادم مع تنبيه.
- **المحرر الغني:** شريط الأدوات يظهر عند التركيز (عريض، مائل، تسطير، ترقيم، نقاط، محاذاة، جداول مع إضافة/حذف صفوف وأعمدة ودمج الخلايا).
- **التعاون:** قفل القسم أثناء تحرير شخص آخر، مع شريط "{الاسم} يحرر هذا الجزء الآن".
- **التوقيع:** نافذة تخيّر بين التوقيع المحفوظ أو الرسم الآن، مع خيار "احفظه للمرات الجاية". وإدارة التوقيع المحفوظ من الملف الشخصي (للمستخدمين غير الضيوف).
- **العرض:** تبويب العرض يعرض الورقة بدون أدوات، مع زر "تحميل PDF".
